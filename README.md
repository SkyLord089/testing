# TOUGE / APEX

Играбельный прототип горного driving-sim на **Godot 4.3+**: Akina и Irohazaka, заднеприводное купе, спуски и подъёмы, Time Attack, свободная езда, погода, рекорды и призрак лучшего заезда.

Проект полностью самодостаточен: дороги, рельеф, лес, автомобиль, интерфейс и звук создаются процедурно. Внешние модели, текстуры, плагины и платные ассеты не требуются.

> **Важно о реализме.** Это не копия BeamNG.drive. Физика построена на `VehicleBody3D` и четырёх raycast-колёсах Godot. Здесь есть масса, подвеска, сцепление, пробуксовка, ABS/TCS, коробка передач и влияние повреждений на мощность, но нет soft-body деформации кузова, термодинамики шин или полной модели Pacejka. Трассы — художественные реконструкции по мотивам реальных мест, а не лазерные сканы.

## Запуск

1. Установите [Godot Engine 4.3 или новее](https://godotengine.org/download/). Подойдёт стандартная, не .NET-версия.
2. Откройте `project.godot` в менеджере проектов.
3. Дождитесь первоначального импорта и нажмите **F5**.
4. Выберите маршрут, режим, направление, время и покрытие — затем **«Начать заезд»**.

Используется Compatibility Renderer (OpenGL), поэтому проект не требует Vulkan. Для экспорта готовы пресеты Linux и Windows; соответствующие export templates нужно один раз установить через **Editor → Manage Export Templates**.

## Управление

| Клавиша | Действие |
|---|---|
| **W / ↑** | Газ |
| **S / ↓** | Тормоз; после остановки — задний ход в автоматическом режиме |
| **A D / ← →** | Рулевое управление |
| **Space** | Ручник |
| **Q / E** | Понижение / повышение передачи в ручном режиме |
| **C** | Камера: преследование → капот → кабина |
| **F** | Фары |
| **R** | Вернуть автомобиль на дорогу (`+5 сек.` в Time Attack) |
| **F1** | Скрыть / показать HUD для скриншотов |
| **Esc** | Пауза / продолжить; закрыть окно настроек |

## Что уже работает

### Маршруты

- **Akina** — примерно **2,62 км**, перепад высот **280 м**. Более широкая дорога, быстрые связки и технические шпильки, кедровый лес.
- **Irohazaka** — примерно **2,89 км**, перепад высот **310 м**. Тесный серпантин с повторяющимися шпильками и осенним лесом.
- Спуск и подъём используют одну дорогу, но независимые старт, прогресс, рекорды и призраки.
- Непрерывный асфальт с коллизиями, корона покрытия, разметка, отбойники с коллизиями, светоотражатели, знаки, стартовые и финишные конструкции.
- Рельеф вырезается вокруг ближайшего участка дороги. Деревья и скалы выводятся через `MultiMesh`, а не тысячами отдельных draw calls.

### Автомобиль

- Купе **Kaido SR-20**, масса 1 280 кг, задний привод, низкий центр масс.
- Независимые `VehicleWheel3D`: настраиваемые пружины, демпферы, ход подвески и сцепление.
- Шесть передач, главная пара 3.5–4.8, автоматический или ручной режим.
- Скоростное ограничение угла поворота руля, ограничитель оборотов, отсечка при переключении.
- ABS и TCS можно отключить. Мокрое покрытие уменьшает сцепление.
- Ручник, угол заноса, пробуксовка, повреждения от резкой потери скорости при ударе.
- Три камеры, фары, стоп-сигналы, процедурный звук двигателя / ветра / шин.

### Игра и интерфейс

- **Time Attack:** обратный отсчёт, три сектора, финиш, штрафы, результат и лучший результат.
- **Free Ride:** тот же маршрут без ограничения по времени и финишного экрана.
- День / закат / ночь; сухо / мокро / дождь.
- Призрак лучшего заезда не участвует в коллизиях.
- Рекорды раздельно хранятся для маршрута, направления и покрытия в `user://touge_apex_records.cfg`; кадры призрака — рядом в `user://*.ghost`.
- Мини-карта, тахометр, скорость, передача, педали, состояние кузова и предупреждения о неправильном направлении.
- Русский интерфейс, пауза, рестарт, фоторежим и настройки автомобиля.

## Проверка

Скрипты не используют глобальные `class_name`, поэтому проект не зависит от предварительно созданного кэша классов редактора.

Сквозной smoke-test:

```bash
godot --headless --path . --script res://tests/smoke_test.gd --fixed-fps 90
```

Он загружает обе трассы, проверяет автомобиль, запускает отсчёт и таймер, ставит игру на паузу, меняет настройки, вызывает восстановление, финиш и возврат в меню. Тест специально не сохраняет новый рекорд.

Обычная проверка импорта проекта:

```bash
godot --headless --editor --path . --quit
```

## Как менять трассу и физику

- Координаты маршрутов находятся в `scripts/route_data.gd`. Каждая точка — `Vector3(x, высота, z)` в метрах. `catmull_rom()` сглаживает центральную линию; дорога, лес, рельеф и мини-карта перестраиваются автоматически.
- Ширина, seed генерации и тип растительности задаются в описании маршрута.
- Жёсткость подвески и сцепление — в `_build_wheels()` файла `scripts/vehicle.gd`.
- Передаточные числа, масса и мощность — рядом с началом того же файла.
- Погодное сцепление меняется в `set_wetness()`. Не ставьте `wheel_friction_slip` слишком высоким без необходимости: это может сделать контакт шины нестабильным.

## Следующие шаги к более серьёзному симулятору

1. Заменить визуальную модель купе на детализированный glTF с интерьером и повреждаемыми панелями.
2. Добавить температуру/износ шин, настройку развала и схождения, телеметрию подвески и Force Feedback.
3. Сделать соперников с записанными линиями или полноценным AI, затем сетевые duel-заезды.
4. Перенести реальную геометрию дорог из легально полученных картографических/фотограмметрических данных.
5. Для уровня BeamNG потребуется отдельная soft-body архитектура; её нельзя получить простым увеличением параметров `VehicleBody3D`.
