# Strafe Lab

Небольшая ASCII-комната от первого лица для движения и стрейфа. На переднем плане — детальные руки в перчатках и AK-47. Мишеней, прицела, панелей и подсказок на экране нет; камера всегда смотрит прямо и мышь не захватывается. Сцена и движение написаны на **Rust**. Статистика не собирается.

Изображение рассчитывается в **4:3 (960 × 720)** и растягивается на поле 16:9, как при игре в CS2 с 4:3 stretched. Комната построена из ASCII-ячеек с перспективой, а оружие и руки — из подробного ASCII-спрайта; никаких изображений во время работы не загружается.

## Готовая сборка

1. Откройте [Releases](https://github.com/SkyLord089/testing/releases) и скачайте архив для своей системы: **Windows x86-64** или **Linux x86-64**.
2. Распакуйте архив. В Windows запустите `strafe-lab.exe`, в Linux — `./strafe-lab`. Сборка Linux требует glibc 2.35 или новее.
3. Нужен современный браузер. Оставьте открытым появившийся терминал; если окно браузера не открылось автоматически, перейдите по адресу, напечатанному в терминале.

Для готовой сборки Rust и Cargo устанавливать не требуется. Контрольная сумма каждого архива находится в файле с окончанием `.sha256`.

## Как запустить из исходников

Нужны установленный [Rust с Cargo](https://rustup.rs/) и современный браузер. Никаких сторонних библиотек или подключения к интернету во время запуска не требуется.

```bash
cargo run --release
```

Программа поднимет локальный сервер и попробует открыть компактное отдельное окно Chrome, Chromium или Microsoft Edge. Если они недоступны, откроется обычный браузер; адрес также будет напечатан в терминале: `http://127.0.0.1:3000/`. Оставьте терминал открытым, а для завершения нажмите в нём **Ctrl+C**.

Если порт занят, можно выбрать другой (или `0` для автоматического выбора):

```bash
cargo run --release -- --port 3001
```

Чтобы собрать запускаемый файл, используйте `cargo build --release`. Он находится в `target/release/` (`strafe-lab.exe` в Windows) и содержит все необходимые файлы. Для показа окна по-прежнему нужен браузер. Можно запустить без автоматического открытия окна: `cargo run --release -- --no-open`.

## Управление

- **A / D** — стрейф; **W / S** — вперёд / назад; **Shift** — медленный шаг.
- **R** — вернуться в исходное положение.
- **F или левая кнопка мыши** — короткая вспышка выстрела. Это только визуальный эффект: мишени и регистрация попаданий отсутствуют.

Мышью крутить обзор не нужно. Физика движения — приблизительная, приложение не подключается к CS2 или программам статистики.

## Для разработки

Репозиторий содержит собранный `web/engine.wasm`, поэтому для обычного запуска цель WebAssembly не нужна. После изменения `src/lib.rs` или ASCII-спрайта в `assets/` пересоберите движок и затем приложение:

```bash
rustup target add wasm32-unknown-unknown
./scripts/build-wasm.sh
cargo run --release
```

В Windows PowerShell вместо shell-скрипта используйте `./scripts/build-wasm.ps1` (если политика PowerShell запрещает скрипты, выполните команды из него вручную). Проверки Rust: `cargo test`. Для дополнительной проверки готового WebAssembly-файла (если установлен Node.js): `node --test tests/wasm.test.mjs`.

Для удалённого предпросмотра можно явно указать `--host 0.0.0.0 --no-open`; в обычном режиме сервер слушает только `127.0.0.1`.

При создании коммита вида `release: vX.Y.Z` (версия должна совпадать с `Cargo.toml`) workflow собирает Windows и Linux, проверяет исполняемые файлы и публикует релиз только после успешных проверок.
