# Настройка мыши: два инструмента

В репозитории два независимых проекта.

| Папка | Что это | Для кого |
|---|---|---|
| [`gmouse/`](gmouse/README.md) | **Rust, Windows 11.** Переназначение кнопок любой мыши, скорость курсора, прокрутка, диагностика HID, поиск vendor-протокола DPI | универсально, в том числе для **ваших** мышей `1D57:2124` и `1A2C:2511` |
| [`mouseconfig/`](mouseconfig/README.md) | Python, кроссплатформенно | только мыши **Logitech** (протокол HID++ 2.0) |

## Про отчёт о вашей мыши

Присланный отчёт показал: **Logitech-мыши нет**. В системе

```
HID\VID_1D57&PID_2124&MI_01   -> Xenta / Eastern Times, 2.4 ГГц приёмник мыши
HID\VID_1A2C&PID_2511&MI_01   -> China Resource Semico / Eastern Times DS2511
```

Ни один из них не поддерживает HID++ (иначе Logitech не нужен, а нужен
`mouseconfig`), поэтому под Windows написана утилита `gmouse`, которая
работает через Win32 API с любой мышью:

* переназначение кнопок (X1/X2, средняя, наклоны колеса) — глобально;
* двойной/тройной клик, прокрутка, сочетания клавиш, запуск программ;
* скорость курсора, строки прокрутки, ускорение указателя;
* показ VID/PID и всех HID-интерфейсов (включая служебный `0xFF00`);
* `probe`/`identify` — поиск команды аппаратного DPI для неизвестного контроллера;
* `diag` — отчёт JSON, по которому дописывается профиль.

Быстрый старт (Windows):

**Скачать готовый `gmouse.exe`:** https://github.com/SkyLord089/testing/releases/latest
(вход в GitHub не нужен), либо собрать самим:

```powershell
cd gmouse
.\build.cmd            # сам доставит нужный линкер, если Visual Studio нет
.\gmouse.cmd list     # обёртка: соберёт при первом запуске и выполнит команду
.\gmouse.cmd test     # узнать имена кнопок
.\gmouse.cmd preset linux-back-forward
.\gmouse.cmd run      # Ctrl+Alt+Q — стоп
```

Тесты и сборка (MSVC и GNU) гоняются в CI:
[`rust-ci.yml`](.github/workflows/rust-ci.yml),
[`release-gmouse.yml`](.github/workflows/release-gmouse.yml).

## Ограничения, о которых стоит знать сразу

* **Аппаратный DPI** у таких мышей почти всегда задаётся кнопкой на корпусе
  или не настраивается вовсе: производитель не публикует протокол.
  `gmouse` меняет то, что применяет Windows (множитель скорости), и умеет
  подобрать vendor-команду, если прошивка её поддерживает.
* Переназначение работает через хук (`WH_MOUSE_LL`). В окнах, запущенных от
  администратора, нужен запуск `gmouse` от администратора; анти-читы игр
  могут блокировать хуки.
* Подсветка, макросы с задержками и профили в памяти мыши — только
  официальным драйвером производителя.
