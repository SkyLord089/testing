# Strafe Lab

Небольшой ASCII-тренажёр стрейфов от первого лица. Перед игроком — неподвижная мишень, в руках справа снизу — стилизованный AK-47: в CS2 это оружие террористов, способное убить с одного попадания в голову. Движение, мишень, попадания и псевдо-3D-рендер написаны на **Rust**. Здесь нет счётчиков, таймеров и сбора статистики.

Изображение рассчитывается в **4:3 (720 × 540)** и намеренно растягивается на поле 16:9, как при игре в CS2 с 4:3 stretched. Положение оружия приближено к максимально низкому и правому; это ASCII-стилизация, а не модель или игровые ресурсы CS2.

## Как запустить

Нужны установленный [Rust с Cargo](https://rustup.rs/) и современный браузер. Никаких сторонних библиотек или подключения к интернету во время запуска не требуется.

```bash
cargo run --release
```

Программа поднимет локальный сервер и попробует открыть компактное отдельное окно Chrome, Chromium или Microsoft Edge. Если они недоступны, откроется обычный браузер; адрес также будет напечатан в терминале: `http://127.0.0.1:3000/`. Оставьте терминал открытым, а для завершения нажмите в нём **Ctrl+C**.

Если порт занят, можно выбрать другой (или `0` для автоматического выбора):

```bash
cargo run --release -- --port 3001
```

Чтобы собрать запускаемый файл, используйте `cargo build --release`. Он находится в `target/release/` (`strafe-lab.exe` в Windows) и содержит все необходимые файлы тренажёра. Для показа окна по-прежнему нужен браузер. Можно запустить без автоматического открытия окна: `cargo run --release -- --no-open`.

## Управление

1. Кликните по полю, чтобы захватить мышь; следующий клик стреляет. **Esc** освобождает мышь.
2. **A / D** — стрейф, **W / S** — вперёд / назад, **Shift** — медленная ходьба.
3. **Мышь** или **стрелки** — обзор, **ЛКМ** или **F** — выстрел, **R** — вернуться в исходную точку.
4. В «Настройках» можно изменить чувствительность. Если захват мыши запрещён браузером, работают стрелки и F.

Для тренировки удерживайте A или D, коротко нажмите противоположную клавишу и стреляйте после остановки. Индикатор внизу поля показывает текущую скорость и примерный момент точного выстрела. Попадание в голову отмечается сразу; мишень не исчезает, патроны бесконечны.

**Важно:** это самостоятельный тренажёр, не подключающийся к CS2 и к внешним программам статистики. Ускорение, торможение, разброс и чувствительность лишь приблизительно имитируют игру, а не воспроизводят её побитово. Браузер по возможности запрашивает сырые движения мыши; DPI, настройки ОС и поддержка браузера могут влиять на ощущение чувствительности. Сохраняется только настройка чувствительности в локальном хранилище браузера.

## Для разработки

Репозиторий содержит небольшой собранный `web/engine.wasm`, поэтому для обычного запуска цель WebAssembly не нужна. После изменения `src/lib.rs` пересоберите движок и затем приложение:

```bash
rustup target add wasm32-unknown-unknown
./scripts/build-wasm.sh
cargo run --release
```

В Windows PowerShell вместо shell-скрипта используйте `./scripts/build-wasm.ps1` (если политика PowerShell запрещает скрипты, выполните команды из него вручную). Проверки Rust: `cargo test`. Для дополнительной проверки готового WebAssembly-файла (если установлен Node.js): `node --test tests/wasm.test.mjs`.

Для удалённого предпросмотра можно явно указать `--host 0.0.0.0 --no-open`; в обычном режиме сервер слушает только `127.0.0.1`.
