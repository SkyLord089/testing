# Очередь проектов

Активен максимум один основной проект и одна маленькая программная задача.

## А. Первый ассет
Объект: выбрать самостоятельно.
Для кого: игровое портфолио или предметная визуализация — выбрать одно.
Готово, когда: есть финальные изображения, файлы открываются, показаны релевантные технические детали, получен хотя бы один содержательный разбор.
Не входит: огромная сцена, собственный движок, десятки вариаций.

## Б. Инвентаризатор ассетов — C++
Вход: путь к тестовой папке.
Выход: список файлов, расширения, размеры и общий объём.
Первая версия: только чтение, без удаления и перемещения, обработка ошибок доступа.
Учебная польза: функции, коллекции, filesystem, вывод в файл.
Проверка: пустая папка, вложенные папки, путь с пробелами и кириллицей, отсутствующий путь.
Особый случай: не обходить бесконечно ссылки и junctions; явно определить поведение.

## В. Карточки повторения
Первая версия без ИИ: вопрос → мой ответ → эталон → дата повторения. Потом добавить вызов локального сервера для объяснения ошибок. Не делать оценку модели единственным критерием правильности.

## Г. Атмосферная презентация
Небольшая 3D-сцена и 30–60 секунд собственного звукового фона. Не обязательна, если цель требует технического игрового ассета без музыки.
