# DualMoE v0.4.1 — нативное приложение для Windows (окно без браузера)

Один самодостаточный исполняемый файл **`DualMoE.exe`** для Windows 10/11 x64: запуск двойным кликом открывает **отдельное окно DualMoE** (Edge WebView2, своя иконка в панели задач, без вкладок и адресной строки). Внутри — тот же движок `VRAM ⇄ RAM (0 чтений HDD)`, `GPU Vulkan ∥ CPU AVX2` и интерфейс **LearnHarness × Hermes Agent (Nous Research)**, оптимизированный под **Ryzen 7 5700X + 16 ГБ DDR4 + Radeon RX 580 8 ГБ Vulkan + HDD + Windows 11**.

## Что нового в v0.4.1

1. **Нативное окно приложения (`DualMoE.exe`)**: интерфейс рисуется в собственном окне Win32 с заголовком «DualMoE v0.4.1», встроенной иконкой (`.ico` + версия `0.4.1.0` в свойствах файла). Закрыли окно — движок остановлен, модель выгружена, порт освобождён, фоновых процессов не остаётся.
2. **Системный диалог выбора модели**: кнопка **«Файл модели…»** открывает стандартное окно Windows (`IFileOpenDialog`) с фильтром `*.gguf`; встроенный обзор дисков остался как резерв для браузерного режима.
3. **Локальный OpenAI API сохранён**: пока окно открыто, `http://127.0.0.1:8090/v1` доступен для LearnHarness / Hermes Agent (по умолчанию порт слушает только `127.0.0.1`).
4. **Мягкая деградация**: если WebView2 Runtime отсутствует (очень старая Windows 10), приложение предлагает установить `aka.ms/webview2` и открывает UI в браузере вместо падения.
5. **Консольная сборка `DualMoE-server.exe`** (артефакт CI) — тот же движок и UI в браузере: для Linux/серверов и отладки.

## Сборка

```bash
# нативное окно (Windows x64, MSVC + Ninja, статический CRT)
cmake -S dualmoe -B build-win -G "Ninja Multi-Config" \
      -DCMAKE_TOOLCHAIN_FILE=$PWD/dualmoe/cmake/x64-windows-msvc.cmake \
      -DLLAMA_SOURCE_DIR=C:/llama-cpp -DGGML_VULKAN=ON -DDUALMOE_DESKTOP_WINDOW=ON
cmake --build build-win --config Release --target DualMoE

# консольный сервер (любая ОС)
cmake --build build-win --config Release --target dualmoe-server
```

Иконка пересобирается скриптом `scripts/make_icon.py` (Pillow) из `assets/icon_source.png`.

Один самодостаточный исполняемый файл **`DualMoE.exe`** для Windows 10/11 x64 со встроенным интерфейсом в эстетике **LearnHarness × Hermes Agent (Nous Research)**, бездисковым режимом **`VRAM ⇄ RAM (0 чтений HDD)`** и 8-этапным инспектором загрузки и сбоев (оптимизирован под **Ryzen 7 5700X + 16 ГБ DDR4 + Radeon RX 580 8 ГБ Vulkan + HDD + Windows 11**).

## Ключевые возможности движка (v0.3.0+ / актуально в v0.4.1)

1. **Режим «Без HDD» (`100% в VRAM + RAM` / 0 обращений к диску во время чата):**
   - Однопроходный линейный предзагрузчик (`FILE_FLAG_SEQUENTIAL_SCAN`, блоки по `16 МБ` по возрастанию смещения на диске) читает модель с механического HDD один раз при старте без рывков головок.
   - При объёме экспертов больше свободной ОЗУ (модели `12–18 ГБ` на ПК с `16 ГБ DDR4 + 8 ГБ RX 580`) автоматически активируется **раздельный обмен `VRAM ⊕ RAM` (`Disjoint Swap`)**: части, хранящиеся в `VRAM`, освобождают свои страницы в `DDR4` (`MEM_DECOMMIT`), экономя до `5 ГБ ОЗУ` и не допуская свопинга Windows в `pagefile.sys` на HDD.
   - Для плотных моделей (`Dense`) используется линейная загрузка `LLAMA_LOAD_MODE_NONE` напрямую в `VRAM + ОЗУ` без страничных промахов на HDD.
2. **Максимальная параллельная нагрузка `GPU ∥ CPU` + Живой обмен `RAM ⇄ VRAM`:**
   - Полный предварительный прогрев слотов банка `VRAM` (`llama_moe_cache_prewarm`) до первого токена.
   - Замкнутый авто-балансировщик с гистерезисом частоты `CRF`: разовые промахи считаются параллельно на ядрах Ryzen 7 5700X по AVX2/FMA из `DDR4`, а реально часто запрашиваемые блоки автоматически поднимаются **`RAM → VRAM`**, вытесняя остывшие слоты обратно **`VRAM → RAM`**.
3. **8-этапный Инспектор загрузки и сбоев + Защита RX 580 / 16 ГБ RAM:**
   - `uBatch <= 32` Guard, `fits_max_buf` Vulkan Guard, защита проекций драйвера AMD Adrenalin, синхронный лог `dualmoe-load.log` и Windows SEH Crash Forensics (`dualmoe-crash.txt`).
4. **Интерфейс LearnHarness × Hermes Agent + OpenAI API:**
   - 3 палитры (**Graphite**, **Nous Cobalt**, **Paper**), встроенный обзор дисков (`C:\`, `D:\`, `E:\`...), живая телеметрия `VRAM ⇄ RAM` и полная совместимость с **LearnHarness** (`http://127.0.0.1:8090/v1`, Model ID: `dualmoe-default`).

## Запуск на Windows 11

1. Скачайте единственный файл **`DualMoE.exe`** со страницы **GitHub Releases (`dualmoe-v0.4.1`)**.
2. Двойной клик — открывается отдельное окно DualMoE (профиль «HDD-Турбо: VRAM ⇄ RAM» включён по умолчанию).
3. В левой панели нажмите **«Файл модели…»**, выберите `.gguf` и нажмите **«Загрузить модель»**.

Модель можно передать сразу: `DualMoE.exe --model D:\Models\gemma-4-26b-a4b.gguf`.
