# DualMoE — Параллельный гибридный MoE-движок (`GPU Vulkan ∥ CPU AVX2 ∥ SSD Arena`)

Компактный C++20 движок для запуска крупных MoE-моделей (`16–40+ ГБ` GGUF) на домашнем ПК с ограниченной видеопамятью и ОЗУ (оптимизирован под связку **Ryzen 7 5700X + 16 ГБ DDR4 + Radeon RX 580 8 ГБ Vulkan + Windows 11**).

## Чем DualMoE отличается от обычного `llama.cpp` и `BigMoeOnEdge`

1. **Истинный параллелизм `GPU ∥ CPU` внутри каждого MoE-слоя:**
   - В VRAM видеокарты размещаются слои `Attention`, `KV-кэш`, роутеры и **ClassLRU-банк самых частых экспертов** (`--vram-cache-mb`, например `2800 MiB`).
   - Исправлена принудительная синхронизация `cb_eval` в планировщике `ggml-backend.cpp`: видеокарта считает попадания кэша в GDDR5 **одновременно** с тем, как ядра Ryzen по AVX2 считают промахи кэша (`--cpu-share 0.92`) прямо в DDR4 — без перегонки гигабайтов холодных весов через шину PCIe.
2. **Полная защита от вылетов на `>= 2` слоях GPU:**
   - В `BigMoeOnEdge` включение 2+ слоёв GPU без ручных regex-оверрайдов пыталось выделить в Vulkan огромные 3D-буферы всех холодных экспертов слоя или обращалось к не-хостовым указателям `tensor->data`.
   - В `DualMoE` при любом `--ngl 2..99` автоматически включается разделение: плотные матрицы идут на GPU, а 3D-матрицы экспертов привязываются к виртуальной арене хоста с поблочным подсчётом ссылок страниц (`page_refs`) и компактным `n_ubatch=256`.
3. **3-уровневая память без лишних чтений SSD и без блокировки NTFS:**
   - Эксперты, попавшие в VRAM-кэш видеокарты (`gpu_expert_hits`), **вообще не читаются с SSD и не занимают слоты DDR4**.
   - Арена экспертов в DDR4 резервирует виртуальное адресное пространство (`VirtualAlloc(MEM_RESERVE)` / `mmap`) и коммитит физическую память строго в рамках `--ram-cache-mb`, возвращая вытесненные страницы ядру ОС (`MEM_DECOMMIT` / `MADV_DONTNEED`).
   - Плотные веса хоста переносятся в анонимную память, а файловый маппинг `.gguf` сбрасывается (`release-mmap`), устраняя сериализацию параллельных чтений драйвером NTFS на Windows.
4. **Встроенная веб-студия `DualMoE Studio` + совместимость с `LearnHarness`:**
   - Веб-интерфейс вшит прямо в бинарник (`http://127.0.0.1:8090`) с живыми графиками скорости, долей `GPU / CPU / SSD` и профилями в 1 клик.
   - На том же порту работает OpenAI API (`http://127.0.0.1:8090/v1/chat/completions`, `/v1/models`) с переиспользованием префикса KV-кэша для длинных сессий `LearnHarness`.

## Как получить готовый `.exe` под Windows 11 + Vulkan (без установки компиляторов)

В репозитории уже настроен облачный сборщик `.github/workflows/build-dualmoe.yml`:
1. Запушь ветку на GitHub и открой вкладку **Actions → Build DualMoE (Windows Vulkan + Linux Gates)**.
2. Скачай готовый артефакт **`DualMoE-win-vulkan-x64`** (`dualmoe-server.exe`, `dualmoe-cli.exe`, `ggml-vulkan.dll` и `start-dualmoe.bat`).
3. Запусти `start-dualmoe.bat` — откроется **DualMoE Studio** на `http://127.0.0.1:8090`.
