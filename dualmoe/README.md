# DualMoE v0.2.0 — Автономный гибридный MoE-движок (`GPU Vulkan ∥ CPU AVX2 ∥ SSD Arena`)

Один самодостаточный исполняемый файл **`DualMoE.exe`** для Windows 10/11 x64 со встроенным интерфейсом в эстетике **LearnHarness × Hermes Agent (Nous Research)** и 8-этапным инспектором загрузки и сбоев (оптимизирован под **Ryzen 7 5700X + 16 ГБ DDR4 + Radeon RX 580 8 ГБ Vulkan + Windows 11**).

## Ключевые возможности v0.2.0

1. **Истинный параллелизм `GPU ∥ CPU ∥ SSD` внутри каждого MoE-слоя:**
   - В VRAM видеокарты размещаются слои `Attention`, `KV-кэш`, роутеры и **ClassLRU-банк самых частых экспертов** (`--vram-cache-mb`), с автоматической проверкой лимита одиночного буфера Vulkan (`fits_max_buf`) для Polaris / RX 580.
   - Убрана лишняя барьерная синхронизация `cb_eval` в `ggml-backend.cpp`: видеокарта считает попадания кэша в GDDR5 **одновременно** с ядрами Ryzen по AVX2/FMA на промахах кэша (`--cpu-share 0.92`).
2. **Комплексная анти-краш защита при загрузке моделей на 8 ГБ VRAM + 16 ГБ RAM:**
   - **`uBatch <= 32` Guard**: микробатч строго согласован с `llama_moe_cache::max_batch = 32`, чтобы `sched_reserve` никогда не обходил кэш слотов и не читал невыделенные `PAGE_NOACCESS` страницы (`0xC0000005`).
   - **Vulkan MMap Guard + `DUALMOE_NO_MMAP_PREFETCH`**: сохраняет целостность внутренних `MEM_MAPPED`-проекций драйвера AMD Adrenalin и отключает мгновенный 20-ГБ `PrefetchVirtualMemory` при открытии крупных `.gguf`.
   - **Авто-адаптация памяти**: проверяет свободную физическую DDR4, лимит виртуальной памяти Windows (`Commit / pagefile.sys`) и остаток свободной VRAM после загрузки весов `Attention`, автоматически снижая `NGL`, `VRAM-кэш` или `RAM-арену` вместо аварийного завершения.
3. **8-этапный Инспектор загрузки и сбоев (Flight Recorder + Crash Forensics):**
   - Живая трассировка всех 8 контрольных точек загрузки в браузере каждые `240 мс`, шкалы **GPU VRAM / Физической DDR4 / Виртуального Commit**, поток логов `Vulkan / llama.cpp`, синхронная запись в `dualmoe-load.log` и перехват аппаратных исключений Windows SEH (`dualmoe-crash.txt`).
4. **Интерфейс LearnHarness × Hermes Agent + OpenAI API:**
   - 3 палитры (**Graphite**, **Nous Cobalt**, **Paper**), встроенный навигатор по дискам (`C:\`, `D:\`, `E:\`...) и папкам, и полная совместимость с **LearnHarness** (`http://127.0.0.1:8090/v1`, Model ID: `dualmoe-default`).

## Запуск на Windows 11

Скачайте единственный файл **`DualMoE.exe`** со страницы **GitHub Releases (`dualmoe-v0.2.0`)** и запустите его двойным кликом — консоль настроит UTF-8 и автоматически откроет интерфейс `http://127.0.0.1:8090` в браузере.
